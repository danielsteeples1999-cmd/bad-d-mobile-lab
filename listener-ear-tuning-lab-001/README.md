# BAD-D Listener Ear Tuning Lab 001

Isolated experimental browser tool. It does not modify BAD-D production.

Purpose:
- identify the listener's actual playback context first;
- collect controlled A/B preference observations;
- allow CANNOT TELL instead of inventing a preference;
- build a small local listener profile;
- keep raw session data device-local.

Promotion rule: observations remain experimental until independently verified and explicitly promoted.

Live page is deployed through GitHub Pages by the workflow in `.github/workflows/deploy-listener-lab.yml`.
